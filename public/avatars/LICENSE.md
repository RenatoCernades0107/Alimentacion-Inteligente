# Avatares / Avatars

Los avatares de esta carpeta se generaron con [DiceBear](https://www.dicebear.com)
(API `https://api.dicebear.com/9.x/<style>/svg?seed=<seed>`) y se guardan como
archivos estáticos para que la app no dependa de la API en tiempo de ejecución.
Cada SVG conserva sus metadatos de autoría y licencia (`<metadata>`).

The avatars in this folder were generated with DiceBear and are stored as static
files. Each SVG keeps its original authorship/license metadata.
